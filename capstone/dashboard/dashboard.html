MIRA — Stakeholder Dashboard (Specification)

The seven metrics MIRA is designed to report once real usage exists. This page is the honest "agreed alternative" to a PowerBI/.pbix artifact for this submission — no PowerBI workspace or .pbix file exists, and no live/production data exists to populate one.

No fabricated numbers. Every card below shows a real, computable metric definition and its exact source table/column in the implemented schema (drizzle/schema.ts) — not an example value. Values read "No production data yet" because no production deployment or live user base exists. See capstone/dashboard/dashboard_documentation.md for full calculation logic and rationale.
No data Shoots created — shoots / period

Top-of-funnel usage signal — the first number that must be non-zero for anything else to mean anything.

mira_shoots.createdAt
No data Invitations sent — invitations

Distinguishes "a shoot was set up" from "a client was actually invited to prepare."

mira_client_invitations.sentAt
No data Invitation delivery rate — %

Share of sent invitations confirmed delivered by the email provider, not just accepted for sending.

mira_client_invitations.deliveryStatus
No data Preparation completion rate — %

Share of invited clients who actually complete Discovery — the signal a static checklist can never produce.

mira_client_invitations.completedAt
No data Readiness rate — %

Share of shoots that reach a real, gated ready_to_shoot state before the shoot date — the metric closest to the product's core promise.

mira_shoots.status
No data Average preparation time — hours

Elapsed time from invitation sent to preparation completed — operational pacing signal for both photographer and product.

mira_client_invitations.sentAt / .completedAt
No data Payment → active-account rate — %

The commercial funnel's core conversion signal. Exactly one verified reference event exists (a €0.00 test transaction) — not a rate.

mira_pending_checkouts.status
