`mira-vision-ocr.swift` is a persistent JSONL worker using macOS Vision locally, accurate English recognition, word/line boxes and no automatic spelling correction of numbers. Compile it with `swiftc scripts/mira-vision-ocr.swift -o .mira-local-data/local-book-tools/mira-vision-ocr`. Native Vision needs local hardware access outside the restricted shell sandbox; a sandbox-only `nilError` is not evidence that a scan is unreadable.

`mira-book-ingest.py --source-dir 'book-brand management' --book-id brand-management` inventories/hashes every part, detects text orientation, handles letterboxed single pages and overlapping spread halves, and writes resumable per-page receipts. It retains full physical images, oriented images, full-page OCR and region OCR. Native observation order is retained; globally sorting lines by their vertical coordinate would interleave columns again. Raw `passages.jsonl` uses exact overlapping character slices. An exclusive local job lock prevents duplicate OCR workers.

`mira-pilot-corrections.py` saves source-checked corrections separately from raw OCR. The pilot table is six columns and 25 brand rows, with explicit row alignment, checked numeric consistency and no guessed font. The funnel has six stages/five transitions. Page 60's overlapping facing-page fragment is excluded only from the checked reading text and remains in raw OCR; note 23 is preserved on its correct right page. Order anchors on pilot pages 13, 30 and 60 are checked, without claiming perfect transcription.

`mira-book-visuals.py --book-id brand-management --describe` inventories every physical page and retains detected figure/table crops. It describes figures using only the approved cloud-disabled local model; tables are held for structural checking. Complete JSON remains `described_needs_review`. The model's output is never automatic approval. `mira-book-table-ocr.py` preserves table OCR/word geometry without inventing cells. `mira-book-repair-descriptions.py` makes one compact, cached local repair attempt only for failed descriptions, retaining prior attempts. Resuming the main visual job does not automatically repeat failed attempts.

`mira-book-audit.py --book-id brand-management` checks every page receipt and verifies raw chunk character coverage. Its printed-page mapping distinguishes OCR-corroborated headers from continuity inference. Confirmed gaps: printed 14–15; duplicated spreads 38–39 and 74–75; incomplete earlier front matter. Part 1 physical page 61 (printed 112–113) is visibly blurred and needs a rescan. Four empty regions were visually checked as blank. Do not equate physical file coverage or complete OCR transport with complete source content.

Up to 20,000 passage items are accepted by the trusted local importer; the 200 editorial-item bound and 2 MB public HTTP import bound remain. The trusted CLI separately caps its file at 80 MB. Existing current-release and withdrawal authority remain in place; context stays bounded to 6,000 characters. Remote seed-job approval/request caps are unchanged.
