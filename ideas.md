# Mira V3 Design Direction

## Experience principle

Mira V3 should feel like entering a quiet editorial studio rather than opening a dashboard. The interaction is paced, spacious, and non-judgmental. One decision appears at a time; secondary controls remain visually quiet. The product never uses gamified scores, progress pressure, trend language, or decorative AI imagery.

## Visual system

Use a warm, mineral neutral palette: parchment, limestone, soft ink, muted clay, and a restrained sage accent. Pair an editorial serif display face with a highly legible humanist sans-serif for controls and body copy. Use generous vertical rhythm, asymmetric editorial grids, thin rules, soft tonal surfaces, and restrained rounded corners. Avoid generic gradient hero sections, glassmorphism, bright SaaS blue, and dense dashboard chrome.

## Journey interaction

The meditation entry uses a full-height quiet composition with a subtle breathing ring implemented in CSS and reduced-motion support. Conversation presents one primary question in a large reading column, with the user’s answer area directly beneath it and prior turns available in a discreet reflection drawer. Progress is stated factually as completed reflections, not as a score.

## Deliverables

The Mirror reads like a short personal essay. The Brand Soul File uses editorial chapters with evidence notes. Visuals That Feel Like You uses deterministic CSS swatches, typographic specimens, composition diagrams, material words, and photography-direction cards derived from confirmed evidence. This avoids invented mood-board imagery and makes provenance visible.

## Accessibility and motion

Maintain strong text contrast, visible keyboard focus, semantic headings, labelled form controls, clear consent language, and mobile-first layouts. Keep interface motion under 300 ms, animate only opacity and transforms, and disable non-essential motion when `prefers-reduced-motion` is enabled.
